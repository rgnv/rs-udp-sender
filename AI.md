# AI Contributions Policy

This project leverages AI-assisted development. All contributions follow these guidelines:

## For Contributors

### Disclosure
- **AI-assisted code must be disclosed** — include an `AI-Assisted: yes` footer in commit messages when AI tools contributed to the change.
- Pull requests containing AI-generated code must check the AI disclosure box in the PR template.

### Accountability
- Every AI-generated contribution **must be reviewed and tested** by a human before merge.
- The human author takes full responsibility for correctness, security, and maintenance.
- AI tools are assistants — **humans make the final decision** on what ships.

## For Maintainers

- Review AI-assisted contributions with the **same scrutiny** as human-only code.
- Watch for: hallucinated APIs, plausible-looking incorrect logic, over-engineered patterns.
- Reject contributions that cannot be explained or justified by the human author.

## Agent-Specific Policy

This codebase was partially generated by AI coding agents (Sisyphus/OpenCode) under human supervision. All agent-generated code was:

1. Verified against the original Go `udp-sender` reference implementation
2. Tested with 43 unit tests (34 pass + 7 root-gated)
3. Integration-tested with byte-for-byte protocol comparison
4. Benchmarked for performance validation (5.6× faster generator throughput)

## References

This project is a Rust rewrite of [Cribl's udp-sender](https://github.com/criblio/udp-sender) — the Go reference implementation.
