## OVERVIEW
Rust rewrite of [Cribl's udp-sender](https://github.com/criblio/udp-sender). 3-binary workspace: UDP sender with per-packet IP/port spoofing via raw sockets, packet generator, SNMP trap generator (v1/v2c/v3 full USM with auth+priv+INFORM). Binary protocol over stdin/stdout.


## CONVENTIONS
- **Error types**: `thiserror` for library errors, `anyhow` for binaries
- **Tests**: inline `#[cfg(test)]` modules, no separate test files
- **Raw socket tests**: all gated with `#[ignore = "requires root/CAP_NET_RAW"]`
- **Logging**: custom ND-JSON logger matching Go's format (lowercase levels, no timestamp, flattened fields)
- **Protocol format**: exactly matches Go binary protocol (magic 0xC1 0x21 0xB1)
- **SNMP v3**: Engine ID `800000020109840301`, salt via `OnceLock<AtomicU64>` seeded from `getrandom` 8B + `fetch_add(1, Relaxed)`
- **INFORM PDUs**: `Reportable=0x04`, DF=0
- **MTU range**: 576..=9000, default 1500
- **Benchmarks**: use TEST-NET-1 `192.0.2.0/24` (RFC 5737)

## ANTI-PATTERNS
- **NEVER** suppress type errors with `as` casts on raw socket types
- **NEVER** add async to the core protocol/sender pipeline — synchronous by design
- **NEVER** change the binary protocol format without updating both Go and Rust generators
- **NEVER** commit `.sisyphus/` plans or internal tooling metadata
- **NEVER** add external crypto dependencies for SNMP v3 key derivation (manual HMAC by design)

## UNIQUE STYLES
- `PacketSender` trait (Go interface parity) for sender implementations
- `ProtocolStream<R: Read>` implements `Iterator` for packet-by-packet processing
- SNMP v3 key derivation uses manual HMAC (no external crypto lib)
- AES-CFB IV construction: `boots(4BE) || time(4BE) || salt(8BE)`
- HMAC truncation: SHA-224→16, SHA-256→24, SHA-384→32, SHA-512→48; MD5/SHA-1→12
